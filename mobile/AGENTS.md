# Expo HAS CHANGED

Read the exact versioned docs for the pinned SDK before writing any native or
config code. Do not write Expo code from memory — the API surface has moved a
lot and plausible-looking calls that no longer exist will typecheck and then
fail at runtime on device.

This package is pinned to **Expo 54** (see `package.json`):
https://docs.expo.dev/versions/v54.0.0/
